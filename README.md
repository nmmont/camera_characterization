# camera_characterization
EE 513 Project 1

This project characterizes the parameters, spatial resolution, noise, dynamic range, and color accuracy of a Google Pixel 9 camera.

Raw images (DNG) are captured utilizing the Open Camera Android App with Camera2 API enabled. 
Only a single lens (main lens 1) is utilized through Open Camera.

Pixel 9 Lens 1 Properties:

 Device Model:    Pixel 9
 
 Focal Length:    6.9 mm
 
 F-stop:          f/1.68
 
 Sensor Shape:    (4080, 3072) (Width x Height)
